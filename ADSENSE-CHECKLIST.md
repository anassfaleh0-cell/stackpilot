# AdSense Pre-Resubmission Checklist — PilotStack

## CRITICAL (Must complete before resubmitting)

- [ ] 1. **Real author profiles** — Create 2-3 author pages at `/authors/[slug]` with real names, photos (or illustrated avatars), LinkedIn URLs, and expertise descriptions
- [ ] 2. **About page founder story** — Add a first-person founder narrative ("I started PilotStack because...") with a real name and verifiable identity
- [ ] 3. **Contact page has real email** — Ensure contact@pilotstack.online forwards to a monitored inbox
- [ ] 4. **Privacy policy updated** — Add mention of Google AdSense specifically, Google's use of cookies for ad serving, and the Data Processing Agreement
- [ ] 5. **Cookie consent blocks AdSense for EU** — Verify the consent banner properly blocks AdSense script until user accepts advertising cookies
- [ ] 6. **Affiliate disclosure visible** — Every page with affiliate links shows a clear "Affiliate Disclosure" notice at the top
- [ ] 7. **No thin content pages** — Every indexed page has 300+ words of unique, valuable content
- [ ] 8. **No duplicate content** — Each comparison/review page has unique editorial content, not just table data
- [ ] 9. **Original images/screenshots** — At least 5 review pages have original screenshots or images of the tools being reviewed
- [ ] 10. **No auto-generated pages without editorial value** — "Best X" pages have unique editorial intros, not just list data

## HIGH PRIORITY

- [ ] 11. **Google Search Console verified** — DNS verification added, sitemap submitted, no crawl errors
- [ ] 12. **Bing Webmaster Tools verified** — Account created and site verified
- [ ] 13. **No 404 errors in Search Console** — Fix or redirect all broken URLs
- [ ] 14. **Mobile-friendly test passes** — All pages pass Google's mobile-friendly test
- [ ] 15. **Page speed optimized** — Core Web Vitals pass (LCP < 2.5s, CLS < 0.1, FID < 100ms)
- [ ] 16. **HTTPS everywhere** — No mixed content warnings
- [ ] 17. **No broken links** — Run a link checker, fix or remove all broken internal/external links
- [ ] 18. **Proper heading hierarchy** — Every page has exactly one H1, proper H2-H6 nesting
- [ ] 19. **Image alt text** — Every image has descriptive alt text
- [ ] 20. **Sitemap.xml accessible** — `pilotstack.online/sitemap.xml` returns valid XML

## MEDIUM PRIORITY

- [ ] 21. **Consistent content updates** — At least 3 new articles published in the last 30 days
- [ ] 22. **No auto-redirects** — No JavaScript-based redirects or cloaking
- [ ] 23. **No pop-ups or interstitials** — No full-screen overlays before content
- [ ] 24. **No misleading ads** — No fake "Download" buttons or misleading CTAs
- [ ] 25. **Content is in English** — All pages are in English (target language)
- [ ] 26. **Proper language declarations** — `<html lang="en">` present on all pages
- [ ] 27. **No login walls** — All content accessible without login
- [ ] 28. **No paywalled content** — All content freely accessible
- [ ] 29. **Site has been live 6+ months** — Domain age sufficient (check WHOIS)
- [ ] 30. **At least 30 unique pages** — Minimum content threshold met (you have 1,873+)

## POST-APPROVAL

- [ ] Place ad code on highest-traffic pages first
- [ ] Monitor for policy violations in AdSense dashboard
- [ ] Ensure ad placements don't interfere with content
- [ ] Set up ad review center to block inappropriate ads
- [ ] Configure ad units for optimal viewability

# Phase 5 — Weekly Execution Checklist (Target: 20 Backlinks/Week)

> The weekly operating rhythm for the Sprint 20 engine. **Target: 20 live backlinks/week at peak** — achieved by volume in directory submissions (high approval share), content syndication, and outreach follow-through. Realistic ramp: Week 1–2 ≈ 5–8 links, Week 3–4 ≈ 10–15, Week 5+ ≈ 20.
> Every item maps to a Sprint 19/20 artifact; check the box, log the link in `growth/19-backlink-tracking.csv`.

---

## Monday — Planning & Pipeline (90 min)

- [ ] Update tracker from last week: move `Submitted` → `Pending`, `Pending` → `Approved`/`Rejected`; record `link_url` + `anchor_text` for every approval
- [ ] Count live links this week vs. 20/week target; if short, add 5 directory submissions
- [ ] Pick 3 linkable assets to pitch this week (from `growth/18-linkable-content-strategy.md`)
- [ ] Review brand-mention alerts (Google Alerts / X / LinkedIn) → add 3 reclamation targets
- [ ] Fill `[First Name]` placeholders on this week's outreach list (from `growth/20-outreach-emails.md`)

## Tuesday — Directory Batch (2–3 hrs)

- [ ] Submit 10–15 targets from `growth/20-submission-packages.md` (copy Section A + card fields → form)
- [ ] Attach logo + screenshots (checklist in `growth/16-submission-assets.md` §11–12)
- [ ] Update each row: status `Submitted`, date
- [ ] Send 5 listing emails (T4) from `growth/20-outreach-emails.md`
- [ ] Reply to any pending directory emails within 24h

## Wednesday — Content Day (4 hrs)

- [ ] Publish/schedule 1 linkable asset or guest post (from the 20 drafted in `growth/20-guest-posts/`)
- [ ] Cross-post to DEV.to / Hashnode / Medium with canonical URL (packages in `growth/20-platform-content/01–03`)
- [ ] 1 Reddit engagement block: reply to 5 threads in target subs (no links, value-first)
- [ ] Share asset on LinkedIn + X with branded anchor link
- [ ] Submit the asset to SaaS Weekly / TLDR Marketing / relevant roundups (T1)

## Thursday — Outreach Day (3 hrs)

- [ ] Send 10 outreach emails (alternate templates T1/T2/T5/T6/T8 from `growth/20-outreach-emails.md`)
- [ ] Send follow-ups due today (day 3/7/14 schedule from `growth/17-outreach-kit.md`)
- [ ] Respond to 2–3 journalist queries on Qwoted / Source of Sources / Featured within 60 minutes
- [ ] Log all sends: status `Submitted`, outreach_template, followup_date

## Friday — Deep Work & Verification (3 hrs)

- [ ] Broken-link building: pull 10 competitor 404 links (Ahrefs) → send 5 T3 emails
- [ ] Verify links earned this week: crawl new backlinks (Ahrefs), check DoFollow/NoFollow, anchor text
- [ ] Update tracker: `Approved` rows complete (link URL, anchor, date, DR)
- [ ] Count weekly total; update `growth/20-weekly-report.md` (create if absent)
- [ ] Prep Monday: next week's directory batch + outreach list

## Weekend — Light (optional, 45 min)

- [ ] Reply to comments on DEV/HN/Reddit posts (24h response rule)
- [ ] Monitor r/SaaS threads; queue 2 thoughtful replies for Monday

## Weekly Volume Budget (to hit 20 links/week at peak)

| Channel | Weekly actions | Expected approvals | Live links |
|---------|----------------|--------------------|------------|
| Directory submissions | 12–15 | 8–11 | 8–11 |
| Guest posts + syndication | 2–3 published | 2–3 | 2–3 |
| Outreach (T1/T2/T4/T5/T6/T8) | 20 sends + 15 follow-ups | 4–7 | 4–7 |
| Broken link (T3) | 5 emails | 1–2 | 1–2 |
| Reddit/HN/community | 1–2 posts + 10 comments | — | 0–1 (NoFollow, brand value) |
| Link reclamation (T7) | 3 emails | 1–2 | 1–2 |
| **Total** | ~55 actions | **15–25** | **≈20** |

## Quality Gates (every week)

- [ ] Zero paid links, zero PBNs, zero spam directories — audit the week's submissions against the Sprint 19 sourcing rules
- [ ] No more than 1 link per outreach email
- [ ] Every approved link recorded with URL + anchor within 24h
- [ ] Anchor diversity: branded (~60%), URL (~20%), topical (~20%) — never repeat the same anchor more than 5×/month

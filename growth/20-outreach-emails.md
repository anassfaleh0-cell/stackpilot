## Sending Protocol

1. Fill `[First Name]` + the two personalization brackets per email (no generic sends).
2. Attach the package from `growth/16-submission-assets.md` (logo PNG, 160-char blurb, 500-char description, screenshots).
3. Send 10 emails/day max (Tue–Thu), then follow up days 3/7/14 using the kit's follow-up sequence.
4. Log every send in `growth/19-backlink-tracking.csv` (status → Submitted, date).
5. On approval → status Approved + link_url + anchor_text. On rejection → Rejected.

## Email Hygiene

- One domain from one mailbox; warm up the address 2+ weeks before the first send.
- Never attach zip files; never send to purchased lists; never include more than 1 link per email.
- CAN-SPAM: postal address + unsubscribe link in every email.
